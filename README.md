# Comunidade IA (nome provisório)

Área de membros (web + app nativo) para uma comunidade de cursos sobre Inteligência Artificial. Assinatura única de R$ 997.

Projeto da Diamond Global. Segue a experiência do MeuFluxo (catálogo de cursos em vídeo com progresso) com uma camada de comunidade leve (comentários por aula + mural de avisos).

> Este é o **App 1**. Um segundo produto ("Dream Life"), clone fiel do MeuFluxo, virá em fase separada.

## Stack

- **API:** Laravel 12 + Sanctum
- **App:** Flutter (iOS + Android)
- **Web:** Vue 3 + Inertia + Tailwind
- **Vídeo:** Bunny Stream
- **Admin:** Filament
